# vehicles_project

La aplicación tiene 4 secciones que resume el conjunto de datos

1) Tabla de datos (mando tipo botón)
Presenta una impresión del DataFrame

2) Histograma (mando tipo botón)
Presentar el histograma del precio de venta de los vehículos

3) Diagrama de dispersión (mando tipo botón)
Presentar la relación del precio de venta de los vehículos y su kilometraje

4) Gráfico de barras (mando checkbox)
Presentar la comparación de la cantidad de vehículos por tipo y su transmisión
